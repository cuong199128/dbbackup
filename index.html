Database Backup Manager

Database Backup Manager là ứng dụng desktop giúp tự động sao lưu (backup) cơ sở dữ liệu theo lịch định kỳ và tải bản sao lưu lên Google Drive của người dùng để lưu trữ an toàn.

Chức năng chính

  • Lên lịch tự động backup database theo chu kỳ do người dùng thiết lập
  • Tải file backup lên Google Drive cá nhân của người dùng
  • Lưu lịch sử các lần backup (thành công/thất bại) để theo dõi
  • Chạy nền qua khay hệ thống (system tray), tự khởi động cùng máy tính
  • Bù lại các lượt backup bị bỏ lỡ khi máy tính tắt hoặc ngủ

Đối tượng sử dụng

Ứng dụng dành cho cá nhân/nội bộ, giúp quản trị viên hệ thống hoặc chủ database tự động hoá việc sao lưu dữ liệu mà không cần thao tác thủ công.
